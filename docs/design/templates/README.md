# Templates

Starting points for the four design-document classes. **Copy** the relevant file out of
this folder — do not edit these in place — rename it, and fill it in.

| Template | Use it for | Copy it to |
|----------|------------|-----------|
| `adr.md` | An Architecture Decision Record | `../adr/NNNN-short-title.md` (next free number; add a row to `../adr/README.md`) |
| `proposal.md` | An enhancement proposal or milestone plan | `../proposals/draft/NNNN-short-title.md` (add a row to `../proposals/README.md`) |
| `spec.md` | A normative, versioned specification | `../specs/<domain>/vN.md` |
| `architecture.md` | An arc42 architecture section | `../architecture/NN-section-name.md` |
